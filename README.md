# Nông Trại KHTN

Web app quản lý lớp học theo phong cách tối giản, luxury và mobile-first.

## Chạy dự án

```bash
npm install
npm run dev
```

## Kiểm tra build

```bash
npm run build
```

## Routes

- `/ta` - Màn hình trợ giảng
- `/admin` - Dashboard admin và modal xuất báo cáo PNG

## Ghi chú

- Giao diện đang dùng mock data để xem trước luồng UX.
- Template báo cáo dùng `html2canvas` và `qrcode.react` để xuất ảnh PNG.
